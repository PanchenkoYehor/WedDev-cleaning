# Клінінг сім'ї Борисенків

Сайт-візитка сімейної клінінгової компанії: про компанію, послуги (квартири, будинки, офіси),
виконані прибирання і форма заявки.

Сайт можна переглянути тут: https://panchenkoyehor.github.io/WedDev-cleaning/

## Структура

```
WedDev-cleaning/
├── images/          # SVG-логотип, іконки, ілюстрації та зображення робіт
├── css/style.css    # стилі
├── js/              # порожня, для скриптів (наступні роботи)
├── index.html       # Головна
├── about.html       # Про нас
├── services.html    # Послуги
├── blog.html        # Виконані прибирання
├── contacts.html    # Контакти + форма заявки
└── README.md
```
